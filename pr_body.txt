🎯 **What:** Removed hardcoded Supabase Anonymous Keys from `delete_cake.js` and `update_pies.js` scripts, replacing them with environment variables.
⚠️ **Risk:** Hardcoding API keys or JWTs directly into the source code is a significant security risk. If the repository is ever made public, or if unauthorized individuals gain access to the source code, these credentials can be extracted and used to access the database or API. Even though it's an "anonymous" key, it shouldn't be exposed in backend scripts, as it's meant to be managed securely.
🛡️ **Solution:** The hardcoded strings were removed. The scripts now load the key dynamically using `require('dotenv').config()` and `process.env.SUPABASE_ANON_KEY`, preventing the key from being committed to version control.
