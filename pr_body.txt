🎯 **What:** The hardcoded `SUPABASE_ANON_KEY` in `app.js` was removed and replaced with a dynamic fallback `(typeof window !== "undefined" && window.ENV?.SUPABASE_ANON_KEY) || "YOUR_SUPABASE_ANON_KEY"`.
⚠️ **Risk:** Hardcoding credentials (even safe ones like an anon key) in version control is flagged by security scanners, as it exposes the key unnecessarily and prevents easy rotation.
🛡️ **Solution:** The codebase now expects the key to be injected at runtime via `window.ENV` or handles the lack thereof gracefully by using local mock data (preserving existing offline fallback behavior). This fixes the vulnerability and ensures the key is never checked into git.
